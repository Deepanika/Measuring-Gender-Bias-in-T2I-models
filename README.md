# Measuring-Gender-Bias-in-T2I-models
DS 307 Research Project

Generated 9*3*2*20=1080 images for GPT and Gemini each

The repo includes the code for generating images, all the prompts used to generate the images, prompts used to write the codebook by VLMs, prompts and rules used to code the images by VLMs and the code for the same, code for determining threshold for reliable analysis, the agreement statistics of VLMs, humans and VLM-human, the detailed results of all the findings.
